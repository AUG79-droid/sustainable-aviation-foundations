# Sustainable Aviation Foundations

English-first static learning experience for the **Sustainable Aviation Learning Lab**.

## What it contains

- Six short modules aligned with the six-pillar architecture.
- Eighteen concise learning sections.
- Six applied decision scenarios.
- Six knowledge checks with feedback.
- Browser-local progress tracking.
- Twelve public official sources, reviewed on 19 July 2026.
- Responsive layouts for desktop, tablet and mobile.
- No build process, framework, external font or runtime dependency.
- `assets/hub-card-sustainable-aviation-foundations.jpg` is the 16:9 image prepared for the Hub card.

## Six pillars

1. Sustainable Operations & Performance
2. Circularity & Materials
3. Responsible Innovation & Digital
4. People, Skills & Culture
5. Resilient Value Chain
6. Climate, Nature & Biodiversity

## Deploy on GitHub Pages

1. Create a new public repository, for example `sustainable-aviation-foundations`.
2. Upload all files and the `assets` directory from this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. Wait for the published GitHub Pages URL and test every module from the corporate network.

Because navigation uses URL hashes, no server rewrite configuration is required.

## Publication governance

This is educational and exploratory content. It does not replace official policies, processes, targets or corporate positions. The images are generated visual concepts and must be validated or replaced with approved corporate photography before official publication.
